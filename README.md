# سنّ — Sun Clinic

كود نظام إدارة عيادة أسنان عربي، مبني من النسخة السحابية رقم **15**.

النسخة الحالية: https://dental-clinic-sadiq.sqiraq31.chatgpt.site

## ما الموجود؟

- ملفات المرضى والحجوزات والزيارات وحالات الأسنان.
- حسابات المدير والطبيب والاستقبال وصلاحيات على الخادم.
- تخصيص العيادات والحقول والأقسام والتصميم.
- صور قبل وبعد وصورة المريض، وخصومات وفواتير وتصدير.
- مراسلات وإشعارات داخلية ومجسم أسنان توضيحي.

## حدود النسخة

الإرسال المباشر عبر WhatsApp Business والمكالمات الداخلية والترجمة الإنجليزية الكاملة ليست مكتملة. مجسم الفك توضيحي، ولا يمثل تشريح المريض أو يقوم بالتشخيص.

هذا مستودع تطوير، وليس نسخة مجهزة للتشغيل بمجرد فتح HTML. لم يُختبر كتثبيت مستقل أو كنشر خارج Sites.

## ملفات المشروع

| المسار | وظيفته |
| --- | --- |
| `source/index.html` | الواجهة الفعلية، بما فيها السكربتات المدمجة |
| `source/worker-api.js` | واجهات الخادم والمصادقة والصلاحيات والتشفير |
| `source/assets/` | مكتبات المتصفح والخط والصورة المرجعية |
| `source/*.js` | نسخ مساعدة لأقسام الواجهة؛ ليست كلها مستوردة تلقائياً |
| `scripts/assemble-worker.py` | يجمع الواجهة والأصول والخادم داخل Worker |
| `scripts/build.sh` | يجهز ملفات النشر داخل `dist` |
| `scripts/validate-artifact.mjs` | يتحقق من بنية ملف النشر |
| `.openai/hosting.example.json` | قالب هوية استضافة لمشروع جديد |

**عند تعديل الواجهة، راجع `source/index.html`. تعديل ملفات الأقسام المساعدة وحدها قد لا يغيّر الواجهة المنشورة.**

## البناء

المتطلبات: Python 3 وNode.js يدعم ESM وBash. على ويندوز استخدم بيئة تطوير مناسبة مثل WSL.

```bash
cp .openai/hosting.example.json .openai/hosting.json
# ضع معرّف مشروع Sites الصحيح في .openai/hosting.json قبل أي نشر.
python3 scripts/assemble-worker.py
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

إنشاء الملفات لا ينشرها. `worker/` و`dist/` نواتج بناء وليست مرفوعة إلى Git.

الخادم مصمم لـ Cloudflare Workers عبر Sites، وليس تطبيق Node تقليدياً. فتح `source/index.html` من القرص لا يشغل المصادقة أو واجهات API.

## الإعدادات والبيانات

القيم المطلوبة على الخادم مدرجة في `.env.example`، بدون أسرار فعلية. ملف المثال لا يُحمّل تلقائياً بواسطة السكربتات.

- قاعدة البيانات والصور والنسخ الاحتياطية السحابية منفصلة في Supabase.
- المستودع لا يحتوي بيانات مرضى حقيقية أو مفاتيح قاعدة البيانات أو تصدير SQL للجداول وسياسات الوصول.
- تشغيل نسخة جديدة يتطلب إعداد الجداول والسياسات ومفاتيح التشفير والمصادقة. المستودع وحده غير كافٍ لاستنساخ بيئة الإنتاج.
- تعتمد المصادقة على هوية ChatGPT التي تمررها منصة Sites. لا تثق بهيدرات هوية يرسلها العميل مباشرة عند النقل إلى استضافة أخرى.
- استُبدلت كلمات مرور التهيئة في المصدر بعلامة `SET_A_UNIQUE_PASSWORD`، وأزيلت أمثلة المرضى والحجوزات. هذه العلامة ليست كلمة مرور صالحة للنشر؛ جهّز إدارة الحسابات قبل تشغيل أي نسخة جديدة.
- حساب مالك النظام محدد في المصدر حالياً؛ راجع تهيئة المالك عند إعداد بيئة مستقلة.
- لا تضف ملفات `.env` الحقيقية أو النسخ الاحتياطية أو صور المرضى إلى Git.
